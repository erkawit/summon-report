# ระบบอัตราค่านำหมายและแบบรายงานผลการส่งคำคู่ความ (ศาลจังหวัดอุดรธานี)

พัฒนาด้วย **Next.js 15 (App Router + TypeScript)** + **TailwindCSS** + **DataTables** + **SweetAlert2** + **Neon PostgreSQL** พร้อมขึ้น **GitHub** และ **Deploy บน Vercel**

## 1. การรันบนเครื่อง (Local Development)
```bash
npm install
npm run dev
```
เปิดเว็บที่ `http://localhost:3000`

> ไฟล์ `.env.local` ถูกเชื่อมต่อกับฐานข้อมูล Neon (`summon-report`) ไว้เรียบร้อยแล้ว และระบบจะสร้างตารางพร้อมนำเข้าข้อมูลตั้งต้น (157 ตำบล 21 อำเภอ ทั้งหมายเงินและหมายฟรี + คำสั่งศาล + ข้อมูลตัวอย่าง) ให้อัตโนมัติในการเรียกใช้งานครั้งแรก

## 2. การนำขึ้น GitHub และ Deploy บน Vercel
1. Push โค้ดขึ้น GitHub Repository (ไฟล์ `.env.local` ถูกกันไว้ใน `.gitignore` แล้ว จะไม่หลุดขึ้น GitHub)
2. ไปที่ [Vercel](https://vercel.com) → **Add New Project** → เลือก Repository นี้
3. ตั้งค่า **Environment Variables** ใน Vercel:
   - `DATABASE_URL` = Connection String ของ Neon PostgreSQL (ดูได้จาก Neon Console โปรเจกต์ `summon-report`)
   - `AUTH_SECRET` = ข้อความสุ่มยาวๆ สำหรับเซ็น Session Cookie (เช่น 32-64 ตัวอักษร)
4. กด **Deploy**

## 3. บัญชีเริ่มต้น
- **ผู้ดูแลระบบ (Admin)**: `admin` / `admin1234`
- **ผู้ใช้งานทั่วไป (User)**: `staff` / `staff1234`

## 4. ความสามารถหลัก
1. **ตาราง DataTables แยก 2 ตารางชัดเจน**: `อัตราหมายเงิน` และ `อัตราหมายฟรี` จัดกลุ่มตามอำเภอ (RowGroup) ค้นหา/กรองตามอำเภอได้
2. **ระบบแอดมิน & จัดการผู้ใช้งาน**: เพิ่ม ลบ แก้ไขบัญชีผู้ใช้งาน กำหนดสิทธิ์ (Admin/User)
3. **จัดการอัตราค่านำหมาย**: เพิ่ม ลบ แก้ไขรายรายการ แก้ไขหัวประกาศ/หมายเหตุ และนำเข้าไฟล์ **Excel (.xlsx)** หรือ **PDF (.pdf)**
4. **ส่งออกอัตราค่านำหมายล่าสุด**: ส่งออก **Excel (.xlsx)** และ **PDF (.pdf)** จริง (ฝังฟอนต์ `TH SarabunPSK`)
5. **คำสั่งศาลแบบ Snapshot**: เพิ่มคำสั่งศาลฉบับใหม่ได้ รายงานใหม่ดึงคำสั่งล่าสุดเสมอ ส่วนรายงานเก่าจะล็อกคำสั่งเดิมไว้ไม่เปลี่ยน
6. **บันทึกข้อความ (Word & PDF)**: สร้าง `.docx` จากไฟล์แม่แบบต้นฉบับโดยตรง (คงฟอนต์ `TH SarabunPSK` และ `TH SarabunIT๙` ครุฑ เส้นประ กล่องข้อความ ตัวหนา-ขีดเส้นใต้ 100%) และส่งออก `.pdf` จริงผ่าน PDFKit ที่ฝังฟอนต์เดียวกัน (ไม่ใช้ PDF Printer ทำงานได้บน Vercel Serverless)
7. **ใบสำคัญรับเงินฟรี (Excel & PDF)**: กรอกเพิ่มทีละแถว ดึง `ราคาหมาย` อัตโนมัติตามตำบล/อำเภอ (แก้ไขได้) และคำนวณ `ราคาเบิก` อัตโนมัติตามเงื่อนไข (100% / หมู่เดียวกันคนละบ้านเลขที่ 50% / บ้านเลขที่ หมู่ ตำบล อำเภอเดียวกัน ขึ้นแดงห้ามบันทึก)
